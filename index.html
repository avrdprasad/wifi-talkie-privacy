WiFi-Talkie Privacy Policy

Effective date: 7 October 2026

1. What WiFi-Talkie Does

WiFi-Talkie is a local wireless voice communication application. It allows participating mobile devices connected to the same local Wi-Fi network to discover one another and communicate using real-time voice transmission.

2. Microphone and Voice Audio

WiFi-Talkie accesses the device microphone when the user activates the voice transmission feature. Microphone audio is used to provide real-time voice communication to participating WiFi-Talkie devices on the local network.

The application is designed for live communication and does not intentionally record or store voice conversations on a WiFi-Talkie cloud server.

3. Local Network Information

To discover and communicate with participating devices, WiFi-Talkie processes network information needed for local communication. This may include a device identifier, device name, local IP address, communication port information, and discovery timestamps.

This information is used for device discovery, determining whether a participating device is available, and establishing direct local voice communication.

4. How Information Is Shared

Voice audio and necessary local-network communication information may be transmitted directly between participating WiFi-Talkie devices on the same local network as part of the application's communication functionality.

WiFi-Talkie does not sell personal information. The application does not use microphone audio for advertising.

The current version does not require a WiFi-Talkie cloud account or a centralized cloud voice server for local voice communication.

5. Internet and Cloud Services

The core voice communication feature is designed to operate over a local wireless network and does not require public Internet connectivity for the direct voice path.

WiFi-Talkie does not intentionally upload voice conversations to a cloud service as part of its core voice communication feature.

6. Data Retention and Deletion

WiFi-Talkie does not intentionally retain voice recordings on a remote server. Local peer-discovery information is used while devices participate in local network communication and may expire when a device is no longer detected.

The current version does not provide user accounts, so there is no WiFi-Talkie account or account profile to delete. Users can stop microphone access through Android permissions and can uninstall the application at any time.

7. Security

WiFi-Talkie is designed to keep its core voice communication within the local network. Users should use a trusted Wi-Fi network and understand that other devices participating in the same WiFi-Talkie network may receive transmissions intentionally sent to them.

8. Children's Privacy

WiFi-Talkie is a general-purpose communication application and is not designed specifically for children. We do not knowingly collect personal information from children for advertising or profiling.

9. Changes to This Privacy Policy

This Privacy Policy may be updated when WiFi-Talkie functionality or data practices change. The updated policy will be published at this same URL with a revised effective date.
